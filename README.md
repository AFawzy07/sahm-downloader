# sahm-downloader
Sahm download manager - releases and updates

## الموقع

الموقع التعريفي لسهم موجود في فولدر `docs/`، وهو HTML وCSS وJS عادي من غير أي أدوات بناء.

- بيجيب آخر الإصدارات تلقائي من GitHub Releases: رقم الإصدار، وحجم الملف، ولينك التحميل المباشر، وملاحظات آخر 3 إصدارات.
- عشان تنشره: **Settings › Pages › Build and deployment** واختار `Deploy from a branch`، والفرع `main`، والفولدر `/docs`.
- هيبقى على: https://afawzy07.github.io/sahm-downloader/

تجربة محلية: افتح `docs/index.html` في المتصفح.
